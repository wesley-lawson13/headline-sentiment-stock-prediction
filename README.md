# headline-sentiment-stock-prediction
Boston College CSCI3349 Final Project: Group 6. Analyzes the sentiment of financial headlines to predict whether the DJIA went up or down on a given day.

___

## Folder Structure

headline-sentiment-stock-prediction/
└── README.md
└── sentiment-analysis/
    └── Folder containing the cleaned data, generated baselines, generated
        word clouds (bag-of-words, tf-idf), as well as the VADER analysis
        in the sentiment-modeling.py file.
